# Student Task Management System

## Project Description

The Student Task Management System is a simple browser-based application for managing student tasks. It allows users to view sample tasks and add new tasks with a title and description.

## Purpose

The purpose of this project is to develop a simple web application while practicing Git version control and DevOps workflows.

## Current Features

- Displays student tasks
- Allows users to add a new task
- Requires a task title and description
- Prevents blank task submissions
- Responsive web page layout

## Project Structure

- `index.html` - Contains the structure and content of the web page.
- `style.css` - Provides the styling and responsive layout.
- `script.js` - Handles adding tasks and input validation.
- `README.md` - Contains project documentation.
- `.gitignore` - Specifies files that should not be tracked by Git.

## Usage Instructions

1. Open `index.html` in a web browser.
2. Enter a task title.
3. Enter a task description.
4. Click the Add Task button.
5. The new task will appear in the task list.

Both the task title and description are required.
